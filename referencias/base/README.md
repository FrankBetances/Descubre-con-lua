# Textos de base del plan docente

Cinco síntesis de trabajo sobre aprendizaje temprano del inglés que sirvieron
de referencia para `docs/PLAN_ARQUITECTURA_PEDAGOGIA.md`. **No son normativa,
ni manuales oficiales, ni documentos de las instituciones que citan.** Son
textos de trabajo, copiados tal como llegaron, con sus errores.

| Fichero | Tema |
| --- | --- |
| `curriculo-ingles-infantil-galicia.txt` | El inglés en el currículo gallego de Educación Infantil |
| `curriculo-vocabulario-infantil-2-6.txt` | Currículo de vocabulario de 18 meses a 6 años |
| `biblioteca-cuentos-dialogicos-bilingues.txt` | Cuentos dialógicos bilingües con Lúa |
| `estrategias-apoyo-linguistico.txt` | Estrategias de apoyo lingüístico de la persona adulta |
| `rutinas-sparkling-sintesis.txt` | Síntesis sobre las rutinas del programa SparkLing |

Antes de llevar nada de aquí a la app:

1. Se mira `ERRATAS.md`. Lo que esté allí no pasa al contenido tal como está
   escrito.
2. Una cifra, un código de criterio o una cita de un estudio se contrasta con
   su fuente primaria. Si no se ha contrastado, no se pinta.
3. Manda la arquitectura docente: si un texto pide algo que la arquitectura
   deja fuera (datos de una criatura, pedir que repita, sesiones de 45
   minutos, lenguaje clínico), no entra.

Esta carpeta está fuera de `docs/` para que el sitio público no la publique.
